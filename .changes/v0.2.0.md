## v0.2.0 - 2026-11-02

### Added

- MCP tool `request_reviews`: agents can request reviews (or send reminders) on Slack for several PRs at once, with the same messages, grouping and tracking as the app's batch "Request review on Slack". Sends follow your Slack send policy and confirmation, and `preview: true` shows the messages without sending.

### Changed

- My PRs now shows the Unassigned section first, above the projects, so PRs still to sort are on top. To review keeps it last.

### Fixed

- Selection after a filter change: the header and the selection bar now show the same count, bulk actions and drag only act on the selected PRs that match the current filters (the bar says how many are hidden and not included), and unchecking Select all clears hidden selections too.
