## v0.5.0 - 2026-11-13

### Added

- When a pull request's base branch requires a merge queue, Squash and merge becomes Add to merge queue, the row and detail show the queue, and the selection menu can add several at once.
- The detail panel lists bot comments and reviews in a Bot reviews section, and human comment counts leave them out. A row shows a bot mark after that detail has been loaded. Settings → Review takes extra bot logins. MCP prompts summarize_pr, prepare_review_request and triage_my_reviews return context text only.
- Copy stand-up recap groups pull requests by status. Review now uses review_sla_hours (default 48). My PRs can hint when over an optional open-PR limit.
- A Bumps due queue lists Slack bumps that are due after a configurable wait (48 hours by default, weekends optional) with no review since the last request. Nothing is posted until you send from that queue.
- Stacked pull requests show their place in the stack, can be grouped in merge order, and the detail panel lists the chain. Merging one whose parent is still open notes that it would land on the parent branch.
- Closing the window leaves PR Nexus in the menu bar. The icon shows how many pull requests need attention, and the menu lists To review and Mine, Refresh, and Quit. Desktop notifications cover a new review request, CI turning red, an approval, and changes requested; new review threads stay off until enabled. The first sync after launch stays quiet, and a denied notification permission is a grey note in Settings.
- A pull request shows an unread dot after new commits, comments, reviews, or CI, and can be snoozed or muted from the selection and detail menus.
- Custom sidebar views save a name and a query. Default views use explicit rules, including bump:due, which stays on this machine.
- Settings → Agents can allow extra hostnames for the local MCP server, so a client in Docker can connect as host.docker.internal. Loopback stays allowed, and the token is still required.

### Changed

- The pull request list has one search field. GitHub qualifiers such as author: and is:draft search GitHub, and other words filter the list on this machine. Sort in the filter menu still orders those results; only a sort: qualifier uses GitHub's order. Reset stays in the filter menu.

### Fixed

- The development server now uses port 1477 instead of the Tauri default 1420, so `bun run tauri dev` no longer fails when another Tauri app's dev server is running.

### Dependencies

- Bump rusqlite to 0.41.1, tauri-plugin-dialog and base64.
