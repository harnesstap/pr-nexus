## v0.5.2 - 2026-11-16

### Added

- Sidebar project rows show how many pull requests they contain, with the same badge as views. A Views header replaces the New view row.

### Fixed

- The list toolbar wraps on a narrow window so the search field, Filters button, and selection bar no longer overlap.
- The local MCP server keeps its listening socket when the extra-host list changes, and Slack sign-in tests keep the loopback socket they bind, so a parallel test cannot take the port.
- The guards job rejects an unreleased Changie fragment that is not valid YAML or is missing kind, body, or time, before Tag release batches it.
