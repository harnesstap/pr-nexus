## v0.3.0 - 2026-11-04

### Added

- Profiles: keep separate GitHub accounts, Slack workspaces, projects, templates, send policy and activity side by side, and switch between them. Your current setup becomes the default profile (a backup of the old database is kept). MCP tools act on the active profile and take an optional `profile`; `list_profiles` lists them.
- Activity → Stats: median and average time to first review of your own PRs (and from a Slack request), PRs opened, merged and waiting, Slack reminders sent, and the most requested reviewers with their response rate and median response time, over 7, 30 or 90 days and per repository or organization. Agents can read the same numbers with the MCP tool `get_review_stats`.
- To review filters with a GitHub search qualifier (org, draft, review decision, CI) now search GitHub, so "N of total loaded" counts the filtered query and Load more pages through it. Projects, groups and the other filters still apply locally.
- Each PR row shows its next action instead of "Review pending": Fix CI, Resolve conflicts, Address review, Ready to merge, Follow up, Review now and more, each with a tooltip saying why and a click that opens the checks, the files or the Slack request. A new "Needs attention" sort orders PRs by that urgency, then by age; it is the default for new installs, and saved sorts are kept.
- Account menu at the bottom left of the sidebar: switch profiles, add one (copying GitHub, Slack workspaces, projects, templates or send policy from existing profiles), and open Settings or About. Settings → Profiles renames and deletes profiles.
- Copy as Markdown in the selection bar (Cmd/Ctrl+Shift+C) copies the selected PRs as a Markdown list of links.
- The Slack request/bump dialogs (one PR or several) have a Copy message icon on each message preview, so you can copy the text and post it in Slack yourself. Copying sends nothing and records nothing.

### Changed

- Quick filters are now compact labelled chips (Draft, No review, CI or conflicts, Changes requested, Ready, Starred) with small counts, inline in the one-row list toolbar. Chips that do not fit fold into More (N), active ones stay visible, empty ones are muted, and Clear filters clears them too.
- Mark all ready in the Slack bulk dialog now takes drafts out of draft in parallel (up to 4 at a time) instead of one after another; each PR clears as soon as it is done and failures are still listed.
- The bulk Slack preview now opens almost at once. Owners of all selected pull requests are resolved in parallel through one GitHub client and reused for 2 minutes, channel names come from a session cache first and are checked on Slack in the background (one read per channel, in parallel), and failed name lookups are no longer retried on every toggle. Send waits for the channel check and still posts to the channel ids.

### Fixed

- The What's new dialog now focuses its Got it button as soon as it opens, instead of one render later.
- Deflake the WhatsNew, PrList, ProjectDialog and release-scripts tests: wait for focus after the effect, give large-list tests an explicit budget, drive the debounces with fake timers, and run release scripts with a clean environment.
- After a team is remapped to another Slack channel, the review preview no longer shows the new channel while bumping the old thread. The default is a new request in the mapped channel with a note on the card, and the old thread stays an explicit pick. Channel names are now read from Slack by channel id (the stored name is only a fallback), the bulk card shows the id only in a tooltip, the mapping editor sets a row's channel with one picker, and Settings flags rows whose saved name is not their channel's.
- Review requests and bumps with several pull requests now show every item as a bullet on its own line in Slack. Before, the first item was glued to the line above with a stray "*". List markers ("- " or "* ") are sent as "•", including in custom templates and notes, so Slack matches the preview.
- With PRs selected and the detail panel open, the selection bar no longer slides under the panel. It stays centered in the list and, when space runs out, folds Add to project and Copy as Markdown into a "…" More menu, then shortens the count and the Slack button. Clear and the Slack button stay visible, shortcuts still work, and toasts follow the bar.
- Settings → Agents: "needs new Slack permissions" no longer loops on Sign in again. The "Create your Slack app" manifest now lists the agent read scopes, and when a new sign-in still lacks scopes, the note names them and says to add them under User Token Scopes on the Slack app's OAuth & Permissions page.

### Dependencies

- Bump async-executor from 1.14.0 (yanked) to 1.14.1 so cargo deny passes.
