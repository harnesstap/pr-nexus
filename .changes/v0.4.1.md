## v0.4.1 - 2026-11-09

### Features

- Slack review requests propose one team per CODEOWNERS line that still needs approval, let you switch the team, merge sends that share a channel, and note a line with no Slack channel. A failing check stays in the request as a note.

### Added

- A view can save a GitHub pull request query. PR Nexus runs it on GitHub and lists the matches, including merged and closed pull requests when the query asks for them.

### Dependencies

- Update rmcp to 3.9.0 so Slack MCP clients cap HTTP response bodies.
