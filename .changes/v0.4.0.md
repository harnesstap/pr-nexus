## v0.4.0 - 2026-11-09

### Added

- PR lists have a repository picker on the toolbar. Choose one or more owner/name values, or clear it to show every repository. It stays on the one toolbar row and combines with search, status filters, and project grouping. The Projects list in the sidebar is alphabetical.
- You can close a GitHub pull request from the detail panel or the selection bar, with an optional comment. The app asks first, leaves the branch in place, and drops the pull request from the open list even when GitHub search is slow.

### Fixed

- A PR merged from the app now leaves the open list right away, its detail panel closes, and a lagging GitHub search on the next refresh no longer brings it back. A failed merge keeps the PR in the list with the error.
- After Mark ready for review, the open Slack preview is planned again. A pull request whose checks are still failing stays skipped. A draft whose latest checks are passing is included, and an owner decision from a different draft or checks state is not reused.
