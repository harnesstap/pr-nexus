## v0.5.3 - 2026-11-18

### Added

- Settings Slack can refresh connected workspaces, and each row shows whether the grant is connected, expired, missing, or unreachable.
- Settings → Agents can switch individual MCP tools off within a capability. A new Slack send tool stays off until it is switched on.

### Changed

- Settings opens one section at a time from a left sidebar, and remembers the last section.
- List polls reuse built rows, and the bot-comment count is stored with the overview instead of parsed on every read.
- The Request review dialog opens from cached owners and channel names, shows Checking channel… while the live name loads, and enables Send when that name is in.
- The Request review dialog shows a stored channel immediately and checks Slack sign-in and code owners in the background.

### Fixed

- Refreshing a Slack workspace keeps that workspace's name with its own domain when auth.test returns another workspace's host.
- Hovering a pull request title shows the full title, and the Enter shortcut only on the focused row.
- Slack MCP calls on one workspace run at the same time: the session lock only covers the client handle, thread reads and author lookups overlap, and startup token checks run across accounts together.
- The Request review dialog follows the live draft state, so Mark ready clears the banner and the send label even when a cached preview arrives late.
