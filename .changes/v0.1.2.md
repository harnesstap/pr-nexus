## v0.1.2 - 2026-11-02

### Added

- In-app release notes. A "What's new" dialog lists the changes since your last version after an update, and Settings → Changelog shows recent releases (built into the app, works offline).

### Changed

- Sync reads your own PRs first and loads review requests only once To review is opened: the newest 100 in the background, with "Load more", a GitHub search as you type, per-stage progress ("Checking my PRs… 40/132") and status checks 4 at a time.

### Fixed

- The setup wizard finds the GitHub CLI when the app is launched from Finder or the Dock (Homebrew and other install places, via the login shell), waits for a macOS keychain prompt, and says plainly when gh is missing or not logged in instead of "No such file or directory (os error 2)".
