## v0.3.1 - 2026-11-04

### Fixed

- OpenCode: Add to OpenCode works with opencode.jsonc (found first, then opencode.json) and writes enabled and oauth: false in the entry. All JSON client files may now hold comments and trailing commas, which are kept. Open config file falls back to the text editor when no app opens the file, with a plain error otherwise.
- Request review on Slack: the dialog no longer opens on an empty "#" target with a channel ID error. A team mapping with a channel name but no ID is now a suggestion that searches for the channel, a mapping row with no channel at all is ignored, and the code-owner channel with an ID is preselected. Search never shows the ID error; no results show a grey hint, and the ID is checked only in Enter an ID. Bulk and request_reviews skip such PRs with a clear reason.
