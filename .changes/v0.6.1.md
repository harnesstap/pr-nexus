## v0.6.1 - 2026-11-24

### Fixed

- The review dialog on Slack prefers a code-owner team that still needs a review, instead of pre-filling the channel of a team that already approved.
- The reviewer-team filter shows a team once per GitHub org and adds the org to the row when two orgs share a team slug or name. A saved filter that has only the slug still matches that team in every org.
- The first pull request in a batch review request now starts on its own line in Slack instead of being stuck to the line above it.

### Dependencies

- Upgrade cookie to 0.18.3 for the private-cookie nonce advisory.
