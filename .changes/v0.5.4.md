## v0.5.4 - 2026-11-20

### Added

- The filter menu can narrow the list to a requested reviewer team or an assignee, and those choices stay in the search field.
- Sidebar views can sit under My PRs or To review, and the Views and Projects headers can be collapsed.
- Custom views can be dragged onto My PRs or To review, or moved there from the menu.
- Pasting a GitHub pull request URL into search opens that pull request, including one from another view or one fetched from GitHub.

### Fixed

- Slack links open only when their host is slack.com or a subdomain of it, and GitHub team lookups encode the org and team names.
- Opening a pull request writes its fresh review, checks, and merge state back onto the list row, and sync fetches the view on screen first.
