## v0.6.2 - 2026-11-26

### Added

- Agents (MCP): new `slack_create_canvas` tool creates a Slack canvas from a title and Markdown content, through the same approval as Slack sends. It is off until you switch it on in Settings → MCP server and needs the `canvases:write` scope, so sign in to the workspace again.

### Fixed

- A pull request whose branch is behind its base is no longer blocked from Slack review requests and bumps. The dialog shows it as a note instead, for example: #42 is behind main.
